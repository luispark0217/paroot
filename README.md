# 파릇 (Paroot)

시험 공부 중간에 들러서 식물 문제 한 개를 풀고, 물과 영양제를 주며 식물을 키우는 힐링 웹앱.

## 파일
- `index.html` — 앱 전체(화면, 스타일, 로직).
- `sw.js` — 오프라인에서도 열리도록 하는 서비스 워커(네트워크 우선).
- `manifest.webmanifest`, `icon.svg` — 홈 화면에 앱처럼 추가할 때 쓰는 정보.
- `vercel.json` — index.html과 sw.js는 캐시하지 않아 새 배포가 바로 보이게 함.
- `api/sync.js` — 아이디·비밀번호 계정 저장 API. Vercel Storage에서 Upstash Redis를 연결하면 동작함.

`main` 브랜치에 커밋하면 Vercel이 자동으로 새 버전을 배포합니다.

## 저장
- 진행 상황은 브라우저(localStorage)에 자동 저장되어, 나갔다 들어와도 이어집니다.
- 도감 > 계정·저장 탭에서 아이디/비밀번호 계정을 만들면 폰·컴퓨터가 같은 정원을 씁니다(3초마다 자동 동기화, 최신 저장본 우선).
- 도감 > 저장 탭의 저장 코드로 다른 기기에 옮길 수 있습니다.

## 게임 규칙 요약
- 게임 시간은 현실보다 12배 빠름(현실 2시간 = 게임 하루). 식물은 낮(6~20시)에만 자람.
- 문제 정답 이슬 5개, 오답 1개.
- 식물 16종, 성장 5단계(씨앗 → 새싹 → 어린 식물 → 자란 식물 → 성숙/꽃/열매).
- 다 자란 열매·허브·꽃 식물은 수확(이슬 보상), 관엽·다육은 꺾꽂이(새 화분)를 할 수 있음.
- 화분 모양 10종(이슬로 구입), 색 9종(무료).
- 걸이 식물 3종(녹영, 립살리스, 수염 틸란드시아)은 천장에 매달려 아래로 자람.
- 빨리 감기: 이슬로 게임 시간을 6시간/하루/사흘 앞당김(물은 알맞게 유지).
- 식물 버리기: 가격의 30% + 성장 단계만큼 이슬을 돌려받음.
- 식물 건강: 흙이 오래 마르거나 젖어 있으면 시듦 → 위독 → 말라버림. '살리기'(이슬)로 되살림. 건강할수록 빨리 자람.
- 빨리 감기: 1시간~7일 15단계, 길수록 시간당 이슬이 적게 듦. 감기 전 어떤 화분이 자랄지 미리 보여줌.
- 접속하지 않은 시간 2분마다 이슬 1개 + 1시간마다 보너스 5개(최대 300), 돌아오면 정원 소식을 알려줌.
