# 파릇 (Paroot)

시험 공부 중간에 들러서 식물 문제 한 개를 풀고, 물과 영양제를 주며 식물을 키우는 힐링 웹앱.

## 파일
- `index.html` — 앱 전체(화면, 스타일, 로직).
- `sw.js` — 오프라인에서도 열리도록 하는 서비스 워커(네트워크 우선).
- `manifest.webmanifest`, `icon.svg` — 홈 화면에 앱처럼 추가할 때 쓰는 정보.
- `vercel.json` — index.html과 sw.js는 캐시하지 않아 새 배포가 바로 보이게 함.

`main` 브랜치에 커밋하면 Vercel이 자동으로 새 버전을 배포합니다.

## 저장
- 진행 상황은 각 사용자의 브라우저(localStorage)에 자동 저장되어, 나갔다 들어와도 이어집니다.
- 도감 > 저장 탭의 저장 코드로 다른 기기에 옮길 수 있습니다.

## 게임 규칙 요약
- 게임 시간은 현실보다 12배 빠름(현실 2시간 = 게임 하루). 식물은 낮(6~20시)에만 자람.
- 접속하지 않은 시간 3분마다 이슬 1개(최대 150), 문제 정답 5개·오답 1개.
- 식물 16종, 성장 5단계(씨앗 → 새싹 → 어린 식물 → 자란 식물 → 성숙/꽃/열매).
